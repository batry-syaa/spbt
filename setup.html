📥 Import from Excel / CSV

No need to type! Upload a file with the columns CLASS + NAME (students) and/or CLASS + BOOK (textbooks). Both can be two sheets in one file, or two separate files. A Google Sheets file works too (File → Download → .xlsx or .csv). In the BOOK list, a CLASS of just 1 to 6 applies to every class in that year.

Add or edit a class

Or edit one class by hand: tap Edit on a class below. Your 12 classes already have the standard KSSR textbooks. If you edit a class later, keep the names spelled the same so their ticks stay.
